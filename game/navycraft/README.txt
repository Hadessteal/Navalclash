NavyCraft Milestone 5G

A naval construction and combat game for Luanti with moving voxel vessels,
careers, factions, NPC fleets, industry, dynamic markets, vessel progression,
merchant convoys, ownership, insurance, capture, salvage, onboarding and
integrated crew-station interfaces.

Administrator setup:
  /port create home Home Harbour
  /port create outpost Outer Anchorage
  /lossmode set standard

Player start:
  /career start
  /faction join navy
  /tutorial status
  /station
  /mission list

Presentation:
  /hud full
  /accessibility status
  /notificationlog

The supplied game folder requires the patched NavyCraft Luanti engine for the
full native moving-construct feature set. Stock Luanti retains development
fallbacks but is not the intended commercial runtime.
